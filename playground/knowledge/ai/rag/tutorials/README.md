# RAG Tutorials

Welcome. These tutorials teach you **Retrieval-Augmented Generation (RAG)** by
building it, one small piece at a time. RAG is the technique behind tools that
can answer questions about *your own* documents (notes, PDFs, company wikis)
instead of only what a model learned during training.

You will build three things, in order:

1. **[Tutorial 1 — Chat with your first document](01-chat-with-your-first-document.md)**
   The smallest possible RAG program. You give the computer one paragraph and
   ask questions about it.

2. **[Tutorial 2 — Search across many documents](02-search-across-many-documents.md)**
   You store many pieces of text and let the computer *find* the relevant ones
   before answering.

3. **[Tutorial 3 — Chat with your PDFs](03-chat-with-your-pdfs.md)**
   You point the program at a real PDF file and ask it questions.

## Who these are for

You do **not** need much programming background. You need:

- A computer where you can install software.
- Willingness to copy, paste, and run commands exactly as written.

Every step tells you what to type and what you should see happen. If what you
see matches, you are on the right track.

## Do them in order

Each tutorial assumes you finished the one before it. Start with Tutorial 1.

## A note on cost

These tutorials use OpenAI's models over the internet. This costs a very small
amount of money (typically a fraction of a US cent per question). You will set
up billing in Tutorial 1.
