# RAG (Retrieval-Augmented Generation)

Notes, tutorials, and experiments on grounding LLMs in retrieved documents.

## Contents

| Path | What's inside |
|------|---------------|
| [tutorials/](./tutorials/) | Step-by-step lessons: chatting with a document, searching across many, chatting with PDFs. |
| [projects/python](./projects/python/) | Standalone scripts (e.g. a local `llama-3-8b-instruct` runner). |
| [projects/page-index](./projects/page-index/) | Page-indexing prototype. |
| [projects/notebooks](./projects/notebooks/) | Exploratory Jupyter notebooks. |
| `wipo_pub_rn2021_18e.pdf` | Reference document used by the PDF tutorials. |

## Convention

Runnable, self-contained experiments live under `projects/`; sequential lessons live under `tutorials/`.
See the [playground README](../../README.md).
